## 🌐 Featured Production Web Application

### 🩺 Sinai Medical Diagnostics — [sinaimedicaldiagnostics.in](https://sinaimedicaldiagnostics.in)

> **Live Website**: [https://sinaimedicaldiagnostics.in](https://sinaimedicaldiagnostics.in)  
> **Source Repository**: [github.com/gbvkoushik/sinaimedical](https://github.com/gbvkoushik/sinaimedical)

**Overview**:  
A vibe-coded healthcare web application built for Sinai Medical Diagnostics. It provides digital diagnostic services, health checkup packages, online test lookup, and doorstep sample collection booking.

#### Key Implementation Details:
- 🧪 **Searchable Test Directory**: 50+ pathology & blood tests with sample preparation guidelines and turnaround times.
- 🏠 **Doorstep Sample Collection**: Interactive booking form with date/slot selection for home lab collection.
- 📄 **Digital Report Status Lookup**: Real-time barcode & sample ID status verification simulator.
- 📱 **Responsive Design System**: Glassmorphism UI built for mobile, tablet, and desktop viewports.
